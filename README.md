# Assignment 3
 HEALTHCARE DATA ANALYTICS AND INSIGHTS
Healthcare Data Analysis

Project Overview

This project focuses on analyzing healthcare data using Excel. The aim is to understand patient health conditions, medical history, hospital charges, and other important healthcare insights.

Tools Used

* Microsoft Excel
* Power Query
* Pivot Tables
* VLOOKUP
* Charts and Dashboard

Data Transformation

* Split customer names into Title, First Name, and Last Name.
* Cleaned and standardized data.
* Converted major surgeries into numerical values.
* Created Weight Status and Diabetes Status columns.
* Merged date columns into Date of Birth.
* Calculated patient age.
* Formatted healthcare charges as currency.

Data Analysis

* Cancer history among smokers and non-smokers.
* Comparison of major surgeries and HbA1C based on transplant history.
* Healthcare charges by weight status and diabetes status.
* Average hospital charges by hospital tier and state.
* Relationship between age, BMI, HbA1C, and healthcare charges.

Dashboard

Created an interactive healthcare dashboard with charts and slicers for Weight Status and Diabetes Status to explore the data and compare healthcare insights.

Conclusion

This project helped me improve my skills in data cleaning, data transformation, data analysis, and dashboard creation using Microsoft Excel.
